# SAO2 実戦カウンター PWA

このフォルダ内のファイルを同じ階層のまま HTTPS のWebサーバーへアップロードしてください。

必要ファイル:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-180.png
- icon-192.png
- icon-512.png

iPhone:
1. Safariで公開URLを開く
2. 共有
3. ホーム画面に追加
4. ホーム画面の「SAO2カウンター」から起動

一度正常に読み込めば、Service Worker により主要ファイルをキャッシュするためオフライン起動にも対応します。

今回の調整:
- iPhoneのDynamic Island / ノッチ分の上余白を自動確保
- 履歴・メモなど内容が短い画面でも下部タブバーを画面最下部に固定
- Service Workerのキャッシュ名を更新し、差し替え後の最新版を取得しやすく調整


[v2.1 改良]
- 履歴の修正・1件削除を追加
- 右下のAT記録を「AT直撃」に変更
- AT直撃の当選契機: GGO詩乃モード / 7図柄打ち抜き / 中段チェリー
- AT直撃確定後はCZのAT当選時と同じAT画面へ遷移
- iPhone safe-area修正は維持

[v2.2 ゲーム数管理の改良]
- 上部の「現在ゲーム数」を「今回ゲーム数」に変更
- 今回ゲーム数はCZ→CZ / CZ→AT / AT→CZなど、直前の当選から今回の当選までの実ゲーム数として管理
- CZ履歴には「今回ゲーム数」と「液晶ゲーム数」を別々に保存
- 液晶ゲーム数はゾーン確認用で、累計ゲーム数には加算しない
- AT中のゲーム数はATゲーム数として累計ゲーム数に加算
- 履歴修正で今回ゲーム数やATゲーム数を直すと、以降の累計Gとページ上部の累計ゲーム数を自動再計算
- 履歴削除時も累計ゲーム数を自動再計算
- 旧v2.1データは累計Gから今回Gを自動復元して引き継ぐ


[v2.3 CZ/AT当選時ゲーム数入力]
- 投資欄下の「現在/今回ゲーム数」手入力パネルを削除
- 累計ゲーム数は、履歴に記録したCZ/AT間ゲーム数 + ATゲーム数から自動算出
- CZ当選記録画面に「CZ/AT間ゲーム数」入力欄を追加
- AT直撃画面に「CZ/AT間ゲーム数」入力欄を追加
- 液晶ゲーム数は従来通り別入力で、累計ゲーム数には加算しない
- 履歴一覧のゲーム数表示を「CZ/AT間G」に統一
- 履歴修正・削除時は累計ゲーム数と各履歴の累計を自動再計算
- AT直撃の当選契機に「引き戻し」を追加
- v2.2以前の未確定 currentGame はv2.3移行時に累計から除外し、履歴と累計の不一致を防止

[v2.4 AT終了時累計ゲーム数入力]
- AT中のゲーム数手入力ボタンを廃止
- AT当選時点の累計ゲーム数を自動保存
- AT結果記録時に、店のゲームカウンターの「AT終了時累計ゲーム数」を入力
- AT中ゲーム数は「AT終了時累計G − AT当選時累計G」で自動計算
- 全体ゲーム数からAT中ゲーム数を引いた残りを通常時ゲーム数として集計
- AT履歴修正もAT終了時累計ゲーム数を入力する方式に統一

[v2.5 画面・入力整理]
- 狙撃手Chance結果ポップアップを画面中央に配置
- AT結果記録画面から当選契機の選択欄を削除
- ATの当選契機はCZ記録またはAT直撃記録から自動で引き継ぐ
- カウンタータブの累計ゲーム数を「全体・通常時・AT中」の3区分で表示
- Service Workerキャッシュ名更新
